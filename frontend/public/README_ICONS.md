# Favicon Icons untuk LCious

File SVG favicon adalah icon utama yang digunakan.

Untuk membuat PNG versions dari favicon.svg, gunakan perintah berikut:

## Dengan ImageMagick:
```bash
convert favicon.svg -resize 32x32 favicon-32x32.png
convert favicon.svg -resize 16x16 favicon-16x16.png
convert favicon.svg -resize 180x180 apple-touch-icon.png
convert favicon.svg -resize 192x192 icon-192x192.png
convert favicon.svg -resize 512x512 icon-512x512.png
```

## Atau gunakan online tools:
1. Upload favicon.svg ke: https://cloudconvert.com/svg-to-png
2. Download dalam berbagai ukuran: 16x16, 32x32, 180x180, 192x192, 512x512

## Icon Design:
- Background: Gradient from red-500 (#ef4444) to orange-500 (#f97316)
- Icon: UtensilsCrossed (lucide-react) dalam warna putih
- Shape: Rounded square (16px border radius)

Favicon SVG sudah bisa digunakan langsung oleh browser modern.
